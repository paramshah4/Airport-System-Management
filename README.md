# Airport System Management

A database-driven airport management system built with Python and PostgreSQL. This project models airport operations including terminals, runways, employees, flights, airlines, and commercial shops using a relational database schema.

## Features

- Interactive console interface for querying and managing airport data
- Pre-written SQL queries and stored procedures
- Support for custom queries, inserts, and updates
- ER Diagram and Relational Schema documentation included

## Tech Stack

- **Language:** Python
- **Database:** PostgreSQL
- **Driver:** psycopg2

## Project Structure

- `console.py` — Main interactive console application
- `my_queries.py` — Pre-written query functions
- `DDL_Script.txt` — Database schema definitions (CREATE TABLE statements)
- `Insert_Script.txt` — Sample data inserts
- `Query.txt` — SQL queries
- `Trigger_01.txt` — Database trigger definitions
- `Stored_Procedure.pdf` — Stored procedure documentation
- `ER Diagram.png` — Entity-Relationship diagram
- `Relational Schema.png` — Relational schema diagram

## Getting Started

1. Set up a PostgreSQL database
2. Run the DDL script to create tables
3. Run the insert script to populate sample data
4. Launch the console:

```bash
python console.py
```
